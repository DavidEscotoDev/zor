5th-Gen Tensor Cores

Native FP4 (4-bit floating point) support delivers up to 2x throughput over FP8. Critical for LLM inference, enabling 70B+ parameter models on consumer GPUs with minimal accuracy loss via quantization-aware training.

Industry-first GDDR7 at 28-32 Gbps. PAM3 signaling delivers 60% more bandwidth per pin vs GDDR6X. 512-bit bus on 5090 enables 1.8 TB/s — eliminating memory bottlenecks in 4K/8K gaming and LLM KV-cache workloads.

Software Development & AI Toolchain

CUDA 12.8 & PTX ISA 8.7

Native Blackwell instruction support. New TMA (Tensor Memory Accelerator) APIs for cluster-level async copy. Improved persistent threads and thread block clusters. FP4/FP6 tensor core MMA instructions exposed via PTX and nvcuda.

TensorRT-LLM / TensorRT 10

FP4 quantization pipeline with calibration. In-flight batching for throughput. Speculative decoding support. Python & C++ APIs. Model optimizer for Blackwell: weight-only quantization, smoothquant, AWQ. TRT-LLM backend for vLLM, TGI.

NVIDIA AI Workbench

Containerized dev environments auto-configured for Blackwell. Project portability across RTX 5000, DGX, and cloud. Integrated with Git, Jupyter, VS Code. Pre-built recipes for Llama, Mistral, Phi, Gemma fine-tuning with LoRA/QLoRA.

Maxine & Video Codec SDK

NVENC 4:2:2 10-bit AV1/HEVC encode. NVDEC 4:4:4 decode. AI video effects (eye contact, super-res, artifact reduction) via Maxine AR SDK. GPU-accelerated FFmpeg/nvcodec headers updated for Blackwell.

OptiX 8 / RTXDI

OptiX 8 adds Shader Execution Reordering hints, cluster acceleration structures, and opacity micromap support. RTXDI (Ray-Traced Direct Illumination) scales to millions of lights. Denoisers optimized for 5th-gen Tensor Cores.

NSight Tools & Profiling

Nsight Graphics/Compute/Systems updated for Blackwell SMs, TMA, and FP4 pipelines. Kernel timeline with cluster-level granularity. Memory throughput analysis for GDDR7. Power profiling per GPC/TPC. Frame capture for DLSS 4 debugging.

Power & Cooling Requirements

RTX 5090 — 575W TGP

Requires 16-pin 12V-2x6 connector (600W rated). Minimum 1000W PSU (1200W+ recommended for OC). 3.5+ slot thickness common. Liquid cooling recommended for sustained loads. Idle ~15W with new media engine.

  • 12V-2x6 (H+) connector mandatory
  • 4× PCIe 8-pin adapters not recommended
  • Case: 360mm+ clearance, 3-slot+ width
  • Airflow: 3× 120mm intake minimum

RTX 5080 — 360W TGP

Single 12V-2x6 connector. 850W PSU sufficient. 3-slot designs typical. Air cooling adequate for most models. New vapor chamber designs on Founders Edition and premium AIB models.

  • 12V-2x6 connector
  • 850W PSU (1000W for heavy OC)
  • Standard ATX 3.0/3.1 compatible
  • 3-slot fits most mid-tower cases

RTX 5070 Ti / 5070 — 300W / 250W

5070 Ti: 12V-2x6, 750W PSU. 5070: 8-pin or 12V-2x6, 650W PSU. 2.5-3 slot. Excellent perf-per-watt for 1440p/4K gaming and entry AI workloads.

  • 5070 Ti: 12V-2x6 preferred
  • 5070: 8-pin legacy support
  • Compact ITX models expected
  • Great for SFF builds

Who Should Buy What

RTX 5090 — No Compromise

4K/8K gaming with full path tracing. Local 70B+ LLM inference. Professional 3D rendering, video production, AI research. Budget not a constraint. Power/cooling infrastructure ready.

RTX 5080 — Sweet Spot

4K high-refresh gaming with DLSS 4. 16GB VRAM handles most local AI (32B-48B 4-bit). Content creation, Unreal Engine 5, Blender. Best price/performance for high-end.
